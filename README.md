# Witherify Skull

**Witherify Skull** is a simple mod for Minecraft that allows you to convert **Skeleton heads** into **Wither heads** by cooking it.

## 📥 Download

- [Modrinth](https://modrinth.com/mod/witherify-skull)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/witherify-skull)
- [GitHub Releases](https://github.com/radsi/witherify-skull/releases)

## 🛠️ Installation

1. Install modloader for Minecraft.
2. Download the latest release.
3. Place the jar file in your `mods` folder.
4. Enjoy!
